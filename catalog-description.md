# Conversation Bookmarks catalog copy

## Display name

Conversation Bookmarks

## Short description

Save conversation and response references with notes and tags, then find your way back in Hermes.

## Full description

Bookmark a Hermes conversation or assistant response with a title, note, and tags. Search and filter saved annotations, see where each one came from, and edit or remove bookmark metadata without changing the conversation. In native Desktop, find a bookmark or save the current chat without leaving it. Optional response-based drafting creates details for review through your configured Hermes provider. Bookmarks stores references, not transcript backups or automatic memories. Works independently or alongside Delivery Shelf under Saved.
