# Conversation Bookmarks catalog copy

## Display name

Conversation Bookmarks

## Short description

Save conversation and response references with notes and tags, then find your way back in Hermes.

## Full description

Bookmark a Hermes conversation or assistant response with a title, note, and tags. Search saved annotations, inspect source availability, and edit or remove bookmark metadata without changing the conversation. Optional response-based generation creates a draft for review through your configured Hermes provider. Bookmarks stores references, not transcript backups or automatic memories. Works independently or alongside Delivery Shelf under Saved.
